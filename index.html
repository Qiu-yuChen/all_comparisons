读数口径（务必先读）
固定参考：全站数值口径的固定参考仍是 OURS-seed2027-step12000；本页额外把 seed2026 / seed2028 的结果展示出来供对照，但这属于展示层面的放开，不改变既有的「固定单一参考、不择优、不取三 seed 均值」口径。
不确定性：三个 seed 的差异本身就是「训练种子敏感性」证据，不是可挑选的自由度。下表的「三 seed 极差」只用来描述敏感程度。
三种「没有值」严格区分：— = 该 prompt 在该方法上没有有效结果（保留在分母，不填 0、不重抽）；不适用 = 协议上未定义（外部基线没有 Teacher 几何；LGM 为高斯表示，点指标不适用）；隔离 = 旧 ULIP 参考受 PointBERT 合批污染，仅供对照，不得用于排名或论文。
图像规格：源图为 512×512 逐视角渲染；本页把 8 个视角下采样到 256×256 后拼成 1024×544 的 WebP（为公开托管而压缩）。所有数值结论一律基于原始未压缩渲染，不基于本页图像。
有效性来源：卡片里的「有效 / 无效」取自修正后的权威逐条结果，而非早期的冻结记录（后者约七成 OURS 记录带修正前状态，会低报无效样本）。完整指标见 全指标总表。

读数说明（与全站一致）

样本范围：10 个方法在 replicate 0 下均具备完整 12 视角的交集，共 1522 条；不满足的样本不出现在本页，也不用其它样本替代。新加入的 seed2026 / seed2028 在原树中 1536 条全部完整，因此没有缩小这个交集。
指标定义：CLIP12 平均 = 每次生成 12 视角取平均 → 两条有效推理重复取平均；CLIP12 最优 = 12 视角取最大，其余相同（均 ×100 显示）。ULIP（逐条修正） 用 point batch=1 重算，解除了旧参考的 PointBERT 合批污染，仅 7 个原生分支有值。占用 IoU / Chamfer（原生坐标） 以 TEACHER-IT 为几何参考，只有原生分支有。PSNR / SSIM / LPIPS 也是以 TEACHER-IT 同 rep 同方位角渲染为参考；TEACHER-IT 自己是参考，因此这三项对它没有定义。
Hunyuan 列：标注为 Hunyuan3D-2 (FR40K accelerated)，是明确采用的加速 Paint 配置，不等于原始标准 Paint。其 CLIP 属于加速后 Paint，Uni3D 属于简化前原 Shape，均不等于最终 FR 网格几何。
本页与数值结论的关系：本页是定性对照，不是数值结论。任何排名请以 全指标总表 的配对口径为准。
